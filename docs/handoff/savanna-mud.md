## 4. Exact Java Contracts (Zero-Lag Rules)

### `SavannaMudBlock` Collision & Feel (Quarter-Block Gradual Slope)
- **Same light opacity across all 6 stages** (zero skylight rebuilds on stage transitions!).
- `cracked` / `drying`: `0.00` sink — full 16px collision (`Shapes.block()`), normal speed.
- `sticky`: **`0.25` blocks sink** — 12px collision (`Block.box(0, 0, 0, 16, 12, 16)`), early ankle drop, gentle drag for non-`#mud_adapted` mobs, squelch sound, captures tracks.
- `soupy_shallow`: **`0.50` blocks sink** — 8px collision (`Block.box(0, 0, 0, 16, 8, 16)`), wading shelf (`0.75×` drag, `#mud_adapted` unaffected), easy jump out.
- `soupy_mid`: **`0.75` blocks sink** — 4px collision (`Block.box(0, 0, 0, 16, 4, 16)`), mid-slope transition (`0.60×` drag, `#mud_adapted` unaffected), easy jump out.
- `soupy_deep`: **`1.00` block sink** — 1px floor (`Block.box(0, 0, 0, 16, 1, 16)` + soft upward buoyancy / easy jump out, **never suffocating/trapping**), brown screen fog overlay if player's eyes dip below top surface.
- Override `isPathfindable` / `getBlockPathType` so `#antcolonies:mud_adapted` mobs navigate smoothly through all stages while non-adapted mobs route around `soupy_mid` / `soupy_deep`.

### `MudCoat` 1-Byte Packed Format (`framework/`)
```java
int packed = ((coverage & 0x7) << 5) | ((dryness & 0x7) << 2) | (tone & 0x3);
```
- **Staggered tick:** Only evaluate once every `60` ticks per mob (`(entity.tickCount + entity.getId()) % 60 == 0`).
- **Passive wading:** `SavannaMudBlock#entityInside` (throttled every 10 ticks) sets `tone`, resets `dryness = 0`, and raises `coverage` proportional to sink depth vs `entity.getBbHeight()`.
- **Gradual water wash-off (user requirement, 2026-11-21):**
  - While `entity.isInWater()` (river/oxbow/pan water): step `coverage` **down by 1 every ~25–30 ticks** (~1.2–1.5 s) when wading, or **every ~15 ticks** when swimming/submerged (`isUnderWater()` / deep water), resetting `dryness = 0` and emitting gentle client-side brown silt-cloud particles tinted by `tone`. Never snap clean in 1 tick!
  - While exposed to rain (`level.isRainingAt(...)`): soften `dryness` toward `0`, then step `coverage` down by 1 every ~80–120 ticks.
- **`MudCoatLayer<T>` (exact match to `YoungPaleLayer`):**
  - Early-out immediately when `coverage == 0` or distance² > `56 * 56`.
  - Resolve mask by `<texture>_mud_{low,full}.png`, falling back to `<geoModel>_mud_{low,full}.png` (handles `crocodile_hatchling` cleanly!).
  - `cov 1..2` → `_mud_low` (alpha `0.58` / `0.94`); `cov 3..4` → `_mud_low` (`0.95`) + `_mud_full` (`0.42` / `0.72`); `cov 5..7` → `_mud_full` (`0.86` / `0.96` / `1.0`). Multiply alpha by `0.84` when `dryness >= 6`.
